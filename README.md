# ✈️ Aerocode - Sistema de Produção de Aeronaves (CLI)

## 📌 Descrição

O **Aerocode** é um sistema desenvolvido em **TypeScript** com interface **CLI (Command Line Interface)**, que simula o processo de produção de aeronaves — desde o cadastro inicial até a entrega final ao cliente.

O sistema permite gerenciar:

- Aeronaves
- Peças
- Etapas de produção
- Funcionários
- Testes
- Relatórios finais

Todos os dados são persistidos em arquivos `.txt`, conforme especificação do projeto.

---

## 🚀 Como executar o projeto

### 📋 Pré-requisitos

- Node.js instalado
- npm ou yarn

---

### ▶️ Passos para rodar

```bash
# Clonar o repositório
git clone <url-do-repositorio>

# Entrar na pasta
cd aerocode

# Instalar dependências
npm install

# Rodar o projeto
npm run dev
